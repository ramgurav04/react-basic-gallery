# 📸 React Basic Gallery

A simple and responsive image gallery built with **React.js** to practice React fundamentals such as components, props, JSX, and state management.

---

## 🚀 Features

- 📷 Display a collection of images
- ⚛️ Built using React functional components
- 🎨 Clean and responsive user interface
- ♻️ Reusable component structure
- 📱 Mobile-friendly layout

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ramgurav04/react-basic-gallery.git
```

### 2. Navigate to the project

```bash
cd react-basic-gallery
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
